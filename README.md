## About Me

I am a Mobile App Developer focused on native Android and iOS development as well as cross-platform apps with Flutter. I build modern, user-centered applications with clear architecture, reusable components, API integrations, local persistence and reliable state management.

My main development areas are:

- **Android:** Kotlin, Jetpack Compose, MVVM/MVI, Coroutines, StateFlow, Room, Retrofit and Koin
- **iOS:** Swift, SwiftUI, MVVM, URLSession, Combine, SwiftData and Firebase
- **Flutter:** Dart, Riverpod, Provider, Dio, Firebase and feature-first project structures
- **Engineering:** Clean Architecture, Repository Pattern, REST APIs, testing, Git/GitHub workflows and CI/CD fundamentals
- **Design:** Responsive UI, Material Design, Apple Human Interface Guidelines and Figma

I am currently expanding my portfolio through practical mobile products and production-oriented development workflows. I am open to Junior Mobile App Developer roles, project collaborations and practical test projects.
